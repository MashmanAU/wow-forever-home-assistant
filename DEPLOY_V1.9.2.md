# Safe v1.9.2 review and deployment

This update uses the existing repository and GHCR workflow. It does **not** require a Home Assistant host reboot, app reinstallation or data migration.

## 1. Review before publishing

1. Extract the review package.
2. Open `repo/prototypes/minimal_image_preview.png` at normal size.
3. Confirm the compact one-row hierarchy: class icon → level → 24h → character name → optional deaths.
4. Review `repo/RELEASE_NOTES_V1.9.2.md` and `repo/prototypes/COMPARISON.md`.

The PNG is generated by the same production renderer from `repo/prototypes/current_leaderboard.json`. Reproduce it from the `repo` directory with:

```powershell
python .\prototypes\render_prototypes.py
```

## 2. Publish with the existing one-command script

Keep the release ZIP outside the clean Git clone. From the cloned repository folder run:

```powershell
powershell.exe -ExecutionPolicy Bypass -File ".\publish.ps1" "C:\path\to\WoW-Forever-Home-Assistant-v1.9.2-review.zip"
```

For the user's current clone, the repository path remains:

```text
C:\Users\jagra\OneDrive\WowForeverBot\wow-forever-home-assistant
```

The script validates the package manifest, safe paths, matching versions and blocked credential/database files; fast-forwards `main`; copies the release; commits `Release WoW Forever v1.9.2`; and pushes to `origin/main`.

## 3. Verify GitHub and GHCR

Wait for both workflows to pass:

- **Test**
- **Build and publish app images**

Confirm both `amd64` and `aarch64` GHCR packages contain tag `1.9.2` before updating Home Assistant.

## 4. Update Home Assistant

1. Create an app-specific backup if desired.
2. Home Assistant → **Settings → Apps → App store → Check for updates**.
3. Confirm **v1.9.2** appears for WoW Forever Level Bot.
4. Select **Update**; do not uninstall or migrate the app.
5. Confirm normal startup, Discord login and command synchronisation in the app log.

The SQLite database remains at `/data/wow_forever.db`; v1.9.2 makes no schema change.

## 5. Validate the production renderer

Keep `leaderboard_render_mode: minimal_image` and run:

```text
/daily-live-test
```

The generated PNG should match the supplied review preview's typography and proportions. The command remains hard-locked to `#bot-stuff`, suppresses mentions and performs no snapshot, commentary or schedule writes.

Rollback only if startup, command sync or both the selected renderer and native fallback fail. Restore the pre-update app backup by its slug; do not run old and new app identities concurrently.
